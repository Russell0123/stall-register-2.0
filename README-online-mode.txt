攤位收銀台 — 線上模式（多裝置共用庫存）設定說明
=================================================

線上模式讓同一個攤位可以被多支手機同時收銀，共用庫存與訂單。
後端是「一份 Google 試算表 + 一支 Apps Script」，只要設定一次，
之後所有線上攤位共用，用 4 碼代碼區分。

離線模式（預設）完全不需要做以下設定，跟以前一樣純本機運作。


--------------------------------------------------
一、建立後端（只需做一次，約 5 分鐘）
--------------------------------------------------

1. 到 https://sheets.google.com 建立一份新的空白試算表，
   名字隨意，例如「攤位收銀台資料」。

2. 在該試算表上方選單點 [擴充功能] → [Apps Script]。

3. 會開啟一個程式編輯頁，把裡面原本的內容全部刪掉，
   改貼上 AppsScript-Code.gs 這個檔案的全部內容，然後存檔（Ctrl+S）。

4. 點右上角藍色的 [部署] → [新增部署作業]。
   - 左邊齒輪「選取類型」→ 選 [網頁應用程式]
   - 說明：隨意填（例如 v1）
   - 執行身分：**我**
   - 誰可以存取：**任何人**        ← 這項很重要，選錯就連不上
   - 按 [部署]

5. 第一次會要求授權：
   [授權存取] → 選你的 Google 帳號 → 會出現「Google 尚未驗證這個應用程式」
   → 點左下角 [進階] → [前往「專案名稱」(不安全)] → [允許]
   （這是你自己寫的程式存取你自己的試算表，所以安全）

6. 部署完成後會給你一段網址，長得像：
       https://script.google.com/macros/s/AKfycb..................../exec
   把它整段複製起來（結尾一定是 /exec）。


--------------------------------------------------
二、在 App 裡設定（每台裝置各做一次）
--------------------------------------------------

1. 開啟 App，首頁右上角點 🎨（設定）。
2. 在「線上同步：Apps Script 網址」欄位貼上剛剛複製的網址。
3. 點 [測試連線]，出現「✓ 連線成功」就完成了。

※ 每台要用線上模式的手機都要貼一次同一組網址。


--------------------------------------------------
三、建立／加入線上攤位
--------------------------------------------------

第一台手機（建立）：
  首頁 [＋ 建立新攤位] → 選「線上模式 · 建立新攤位」
  → 填攤位名稱、日期 → [建立]
  → 系統會給一組 4 碼代碼（例如 K7PQ），畫面上方會顯示「● 線上 K7PQ」

其他手機（加入）：
  首頁 [＋ 建立新攤位] → 選「線上模式 · 加入既有攤位」
  → 輸入那 4 碼代碼 → [建立]
  → 雲端上該攤位的商品、庫存、訂單會整份同步下來

代碼不分大小寫，也不會用到容易看錯的 0 O 1 I L。


--------------------------------------------------
四、線上模式的運作方式
--------------------------------------------------

* 每 1 分鐘自動拉一次最新庫存。
* 切到「結算」頁時會額外立刻拉一次。
* 也可以點畫面上方的「● 線上 XXXX」手動立即同步。

* 結帳一定即時連伺服器驗證，不會只信本機快取：
    成功 → 伺服器在鎖定狀態下扣庫存、寫訂單，回傳最新庫存
    失敗 → 完全不動庫存，在 Failures 分頁寫一筆失敗原因，
           手機跳出「結帳失敗：庫存不足」並附上原因，
           購物車會保留，庫存同步成最新數字，調整後可再送一次
  多台手機同時結帳時，由 Apps Script 的 LockService 排隊處理，
  不會超賣。

* 沒網路時結帳會直接擋下，不讓送出，並提供「轉為離線模式」的選項。

* 修改商品／套組後會自動把目錄推上雲端，其他裝置下次同步就會看到。


--------------------------------------------------
五、轉為離線模式（單向、不可逆）
--------------------------------------------------

攤位內點上方攤位名稱 → 編輯攤位 → [永久轉為離線模式]
需要連續兩次確認。轉換後：
  - 以「最後一次同步到的庫存與訂單」作為本機基準值固定下來
  - 之後完全不再連線，其他裝置的變動不會再同步過來
  - 無法再轉回線上模式

（離線攤位也無法升級成線上攤位，這是設計上的單向限制。）


--------------------------------------------------
六、試算表裡會看到什麼
--------------------------------------------------

程式第一次執行時會自動建立這些分頁：
  Stalls    攤位索引（代碼、名稱、擺攤日期、更新時間）
  Catalog   商品目錄（JSON，太長會自動切成多列）
  Stock     庫存：一個規格一列，可直接看到每項還剩幾個、賣了幾個
  Orders    訂單紀錄：每筆一列，含明細 JSON
  Failures  結帳失敗紀錄：時間、原因、當時的購物車內容

建議只看不要手動改；真要改，改 Stock 分頁的數字最安全。


--------------------------------------------------
七、注意事項與已知限制
--------------------------------------------------

* 「誰可以存取」一定要選「任何人」。若選成「任何人（需登入 Google）」，
  手機端會連不上。

* 之後若更新了 Code.gs，必須重新部署才會生效：
  [部署] → [管理部署作業] → 鉛筆圖示 → 版本選「新版本」→ [部署]
  （網址不會變）

* 安全性：知道網址＋4 碼代碼的人就能讀寫該攤位資料。
  這是為了「不用登入就能多機共用」而做的取捨，請勿存放個資。
  代碼共約 92 萬組，仍建議不要把網址公開分享。

* 商品圖片也會一起同步。圖片多的攤位第一次加入會比較慢，
  建議圖片不要放太多張，或線上攤位少用圖片。

* 沒網路時對線上攤位「修改商品」的變更只會留在本機，不會排隊補送。
  連上網後請再存一次該商品，才會同步上去。

* 刪除線上攤位只會從這台裝置移除，雲端資料與其他裝置不受影響。

* 攤位副本一律是獨立的「離線」攤位，不會連到原本的雲端攤位。
